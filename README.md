# ذِكر (Dhikr) 🌙

تطبيق أندرويد بسيط وهادئ لعدّ الأذكار وتنظيمها وإتمامها يوميًا.
**بلا إعلانات • يعمل بدون إنترنت • بلا صلاحيات • بياناتك على جهازك فقط.**

> فعّل «التثبيت من مصادر غير معروفة» على هاتفك قبل التثبيت. يتطلب أندرويد 7.0 (API 24) أو أحدث.

## ✨ المميزات

### 🔢 العدّادات
- أنشئ عدّادات متعددة بأسمائك (استغفار، أذكار الصباح، …) مع **هدف اختياري** (33، 100، …).
- **نقرة واحدة** تزيد العدّ.
- **ضغطة مطوّلة**: تصفّر العدّاد إن كان أكبر من صفر، وعلى الصفر تعرض تأكيد الحذف.
- عند بلوغ الهدف: تظهر **طبقة احتفال بصرية صامتة** ويتحول العدّاد إلى اللون الذهبي (بلا موسيقى أو أجراس).

### 🔈 الصوت
- صوت نقر عند كل ذِكر (اختياري).
- صوت مميز عند إتمام الهدف (اختياري).
- الأصوات **مولَّدة برمجيًا** على شكل نقرات قصيرة، بلا نغمات موسيقية ولا ملفات صوتية.
- لا توجد اهتزازات.

### 📊 الإحصائيات والإنجازات
- إجمالي الأذكار وإجمالي الأهداف المنجزة في أعلى الشاشة الرئيسية.
- شاشة إنجازات بشارات تُفتح تلقائيًا: الهدف الأول، ١٠٠ ذكر، ٥٠٠، ١٠٠٠، ٥٠٠٠، ١٠٬٠٠٠ ذكر، ١٠ أهداف، ٥٠ هدفًا.

### 🎯 وضع التركيز
- شاشة خالية من أي شيء سوى الرقم، ومساحة نقر تملأ الشاشة، وتبقى الشاشة مضاءة.
- **منع التحايل**: إذا غادرت التطبيق أو أُطفئت الشاشة يتوقف العدّ، وتظهر رسالة لطيفة تطلب منك العودة والمتابعة.
- للخروج: إيماءة أو زر الرجوع في النظام.

### 📖 رسالة اليوم
- شريط صغير أسفل الشاشة الرئيسية يمكن إغلاقه، ويفتح قارئًا بملء الشاشة.
- آية أو حديث أو حكمة تتغير تلقائيًا **كل 24 ساعة**، مع زر **نسخ**.

### 🚀 التعريف والحفظ
- شرح من 4 خطوات عند أول تشغيل.
- كل شيء محفوظ محليًا (Room + SharedPreferences) فلا تضيع بياناتك.

## 🧱 التقنيات

| الجانب | الاختيار |
|---|---|
| اللغة | Kotlin |
| الواجهة | Jetpack Compose + Material 3 |
| التخزين | Room (العدّادات) + SharedPreferences (الإعدادات والإحصائيات) |
| البنية | MVVM: ‏`ViewModel` ← `Repository` ← `Room` |
| الصوت | `AudioTrack` يولّد نقرات من ضوضاء مفلترة |
| الاتجاه | RTL كامل بأرقام عربية هندية |
| الحد الأدنى | Android 7.0 (API 24) |

## ➕ إضافة رسائل جديدة

أضف عناصر إلى `app/src/main/assets/messages.json` بالشكل التالي:

```json
{ "type": "آية", "text": "نص الرسالة", "source": "المصدر" }
```

القيم المقترحة لـ `type`: ‏`آية` أو `حديث` أو `حكمة`. تُختار رسالة كل يوم تلقائيًا من القائمة، فكلما زادت العناصر زاد التنوع.

> ⚠️ يُرجى مراجعة نصوص الآيات والأحاديث مع مختص قبل أي نشر عام.
